cleanvim.lua

A modular, minimal, and transparent Neovim distribution.

Clear structure, no hidden abstraction, fast through lazy-loading.

github how it works install keys plugins

philosophy

  • Explicit. One plugin, one file. You can tell what a file does from its path.
  • Predictable. Your choices of theme, diagnostics, transparency and format-on-save stay saved between sessions.
  • Extend, don't fork. Add, switch and toggle without editing core files.
  • Fast. Plugins load lazily, only when you need them.
  • Zero setup. Tree-sitter parsers install themselves the first time you open a language.

install

Needs Neovim 0.11+ and a Nerd Font.

# back up your current config
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak

# clone
git clone https://github.com/Cyrus-Gahatraj/cleanvim ~/.config/nvim

# launch: lazy.nvim installs itself on first run
nvim

layout

lua/cleanvim/
├── core/      options, keymaps, autocmds
├── config/    defaults and saved state
├── languages/ one file per language
├── plugins/   one spec per plugin
│   └── custom/  your plugins go here
├── ui/        themes, transparency, diagnostics
└── lazy.lua   plugin manager bootstrap
